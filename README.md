# Калькулятор раскроя труб для сварных изделий

Полностью офлайн PWA-приложение для расчёта оптимального раскроя труб номинальной длиной с допуском на сварные изделия из нескольких отрезков.

## Возможности

- Все размеры — миллиметры.
- Расчёт ведётся по минимальной длине трубы `L_calc = L_nom − Δ`.
- Подбор разбиения каждого изделия: максимизация основной части, ограничения «доп ≥ 1000 мм, доп ≤ 40% от основной, все отрезки ≤ 9500 мм».
- Поддержка 1 шва (2 части) и 2 швов (3 части).
- Раскрой по алгоритму First-Fit Decreasing с группировкой пайплайнов в одинаковые паттерны.
- Графическая схема раскроя каждой трубы (горизонтальная полоса с цветными блоками и отходом).
- История расчётов в `localStorage`, удаление отдельных записей и очистка целиком.
- PWA: manifest, service worker, offline-кэш, добавление на главный экран (iOS/Android), мета-теги iOS.

## Использование

Откройте `index.html` в браузере или разверните файлы на любом статическом хостинге (GitHub Pages, Netlify, локальный HTTP-сервер). Для полноценного PWA (установка, offline) приложение должно открываться по HTTP(S), а не `file://`.

Локальный запуск для тестирования:

```bash
python3 -m http.server 8080
# затем откройте http://localhost:8080
```

## Сборка Android APK через WebView

1. Создайте Android Studio проект с одним `WebView`.
2. Скопируйте файлы (`index.html`, `app.js`, `styles.css`, `manifest.webmanifest`, `sw.js`, `icon-*.svg`) в `app/src/main/assets/`.
3. Загрузите главную страницу в WebView:

```kotlin
val webView = findViewById<WebView>(R.id.webview)
webView.settings.javaScriptEnabled = true
webView.settings.domStorageEnabled = true  // нужно для localStorage
webView.loadUrl("file:///android_asset/index.html")
```

> При работе через `file://` Service Worker может быть недоступен, но приложение само по себе автономно и не требует сети.

## Алгоритм

1. `L_calc = L_nom − Δ`. Если ≤ 0 — ошибка.
2. Для каждого изделия `L_i` ищется разбиение:
   - **1 шов**: перебор `L_main` от `max(1000, ⌈L_i/1.4⌉)` до `min(9500, L_i − 1000)`; берётся максимальный с допустимым `L_add = L_i − L_main`.
   - **2 шва**: перебор `L_main` от `max(1000, ⌈L_i/1.8⌉)` до `min(9500, L_i − 2000)`; `L_add1 + L_add2 = L_i − L_main`, оба ≥ 1000, ≤ 40 % от основной.
3. Все отрезки сводятся в типоразмеры с количествами.
4. Раскрой решается жадным алгоритмом FFD (отрезки в порядке убывания длины раскладываются в первую трубу, куда помещаются; иначе открывается новая).
5. Трубы с идентичным составом группируются в паттерны.
