# Калькулятор раскроя труб для сварных изделий

Приложение помогает рассчитать, как с минимальными отходами разрезать трубы на отрезки для изготовления сварных конструкций (например, трубогибочных заготовок).

## Что задаёт пользователь

- Длину исходной трубы с допуском (например, 11500 ± 100 мм).
- Один или несколько типов готовых изделий — для каждого указывается нужная длина и количество (например, 192 шт по 11080 мм и 192 шт по 12120 мм).
- Количество сварных швов в изделии (1 или 2) — изделие состоит из основной части и одного или двух привариваемых кусков.

## Производственные ограничения

- Любой отрезок не короче 1000 мм и не длиннее 9500 мм.
- Каждый привариваемый отрезок не больше 40 % от длины основной части.
- Расчёт ведётся по минимально возможной длине трубы (номинал минус допуск), чтобы гарантировать выполнимость плана при колебаниях.

## Что делает приложение

- Для каждого изделия автоматически подбирает оптимальные длины основной и дополнительных частей, соблюдая все ограничения.
- Решает общую задачу раскроя: как комбинировать эти отрезки на трубах, чтобы израсходовать минимум труб и получить минимум отходов.
- Показывает наглядную схему раскроя каждой трубы с цветными блоками, линиями реза и размерами в миллиметрах.
- Выводит общие итоги: количество труб, суммарный отход в мм и в процентах.

## Дополнительные возможности

- Можно сохранять расчёты в историю с собственными названиями (например, «Заказ №152»), просматривать и удалять их.
- Работает полностью автономно, без интернета.
- Устанавливается на iPhone (через Safari «На экран „Домой“») и на Android как обычное приложение (PWA или APK).

## Как запустить

### Самый простой способ — однофайловая версия

Откройте `raskroy.html` в любом браузере (двойной клик на ПК или «Открыть» на телефоне). Файл содержит всю разметку, стили и логику; интернет не требуется.

### Полноценная PWA на хостинге

Разверните содержимое репозитория на любом статическом хостинге (GitHub Pages, Netlify, локальный HTTP-сервер) и откройте `index.html`. Для полноценной установки PWA приложение должно открываться по `https://`, а не `file://`.

Локальный запуск:

```bash
python3 -m http.server 8080
# затем откройте http://localhost:8080
```

## Android APK через WebView

1. Создайте Android Studio-проект с одним `WebView`.
2. Скопируйте файлы (`index.html`, `app.js`, `styles.css`, `manifest.webmanifest`, `sw.js`, `icon-*.svg`) в `app/src/main/assets/`.
3. Загрузите главную страницу в WebView:

```kotlin
val webView = findViewById<WebView>(R.id.webview)
webView.settings.javaScriptEnabled = true
webView.settings.domStorageEnabled = true  // нужно для localStorage
webView.loadUrl("file:///android_asset/index.html")
```

## Алгоритм (кратко)

1. `L_calc = L_nom − Δ`. Если ≤ 0 — ошибка.
2. Для каждого изделия `L_i` ищется разбиение:
   - **1 шов**: перебор `L_main` от `max(1000, ⌈L_i/1.4⌉)` до `min(9500, L_i − 1000)`; берётся максимальный с допустимым `L_add = L_i − L_main`.
   - **2 шва**: перебор `L_main` от `max(1000, ⌈L_i/1.8⌉)` до `min(9500, L_i − 2000)`; `L_add1 + L_add2 = L_i − L_main`, оба ≥ 1000, ≤ 40 % от основной.
3. Все отрезки сводятся в типоразмеры с количествами.
4. Раскрой решается жадным алгоритмом First-Fit Decreasing (FFD): отрезки в порядке убывания длины раскладываются в первую трубу, куда помещаются; иначе открывается новая.
5. Трубы с идентичным составом группируются в паттерны.
