О программе

Калькулятор раскроя труб для сварных изделий. Полностью офлайн-приложение (PWA).

  • Все размеры — миллиметры.
  • Расчёт ведётся по минимальной длине трубы: L_calc = L_nom − Δ.
  • Основная часть ≤ 9500 мм. Привариваемые отрезки ≥ 1000 мм и ≤ 40% от длины основной части, ≤ 9500 мм.
  • Выбирается разбиение с максимальной основной частью; при равенстве — с минимальной суммой дополнительных.
  • Минимизируется количество труб (приоритет), затем общий отход.
  • Алгоритм раскроя: жадный FFD по убыванию длин с группировкой повторяющихся паттернов. Для небольших задач выполняется уточняющий локальный поиск.
  • Данные сохраняются в localStorage. Можно установить на домашний экран как PWA.
